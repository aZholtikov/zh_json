## Обзор

`zh_json` — это легковесный компонент JSON сериализации для ESP-IDF (Espressif IoT Development Framework). Он предоставляет простой и эффективный способ создания JSON объектов и массивов в приложениях ESP32. Компонент поддерживает добавление различных типов данных (строки, целые числа, числа с плавающей точкой, булевы значения) и вложенных структур (объекты и массивы).

Компонент разработан специально для микроконтроллеров ESP32 и использует функции управления кучей ESP-IDF для оптимального выделения памяти с различными параметрами памяти (внутренняя/внешняя RAM).

---

## Возможности

1. **Поддержка различных типов данных**: Строки (char*), целые числа (int), числа с плавающей точкой (float), булевы значения (bool)
2. **Вложенные структуры**: Поддержка вложения JSON объектов и массивов
3. **Автоматическое управление памятью**: Автоматическое выделение и освобождение памяти для имен и значений
4. **Динамическое изменение размера**: Емкость JSON автоматически увеличивается при добавлении элементов
5. **Максимальная емкость**: До 65 535 элементов (ограничение 16-битного индекса)
6. **Оптимизировано под ESP-IDF**: Использует функции heap_caps для выделения памяти с параметрами памяти
7. **Обработка ошибок**: Комплексная проверка ошибок с детальным логированием
8. **Потокобезопасность**: Не является потокобезопасным по умолчанию (можно сделать потокобезопасным с внешним мьютексом)
9. **Минимальные накладные расходы**: Низкие накладные расходы на память и процессор

## Справочник API

### Структура zh_json_t

```c
typedef struct
{
    void **names;        // Массив указателей на имена JSON полей
    void **values;       // Массив указателей на значения JSON
    void **types;        // Массив указателей на типы JSON значений
    uint16_t capacity;   // Максимальная емкость JSON
    uint16_t size;       // Количество элементов в JSON
    bool is_initialized; // Флаг состояния инициализации JSON
} zh_json_t;
```

---

### zh_json_init()

Инициализирует JSON структуру.

**Параметры:**

- `json` - Указатель на структуру JSON

**Возвращает:**

- `ESP_OK` - Успех
- `ESP_ERR_INVALID_ARG` - Неверный аргумент (NULL json)
- `ESP_ERR_INVALID_STATE` - JSON уже инициализирован

**Пример:**

```c
zh_json_t json = {0};
zh_json_init(&json);
```

---

### zh_json_free()

Деинициализирует JSON и освобождает всю выделенную память.

**Параметры:**

- `json` - Указатель на структуру JSON

**Возвращает:**

- `ESP_OK` - Успех
- `ESP_ERR_INVALID_ARG` - Неверный аргумент (NULL json)
- `ESP_ERR_INVALID_STATE` - JSON не инициализирован

**Примечание:** Вся динамически выделенная память для имен и значений также освобождается.

- `ESP_ERR_INVALID_ARG` - Неверный аргумент (NULL json или value)

## Примеры использования

### Создание простого JSON объекта или массива

```c
#include "zh_json.h"

void app_main(void)
{
    esp_log_level_set("zh_json", ESP_LOG_ERROR);
    zh_json_t json = {0};
    zh_json_init(&json);
    zh_json_add_char(&json, "Name 1", "Hello world!");
    zh_json_add_int(&json, "Name 2", -123456);
    zh_json_add_float(&json, "Name 3", 1234.56789, 2);
    zh_json_add_bool(&json, "Name 4", true);
    char buffer[128] = {0};
    zh_json_object_create(&json, buffer);
    printf("JSON object %s.\n", buffer);
    zh_json_array_create(&json, buffer);
    printf("JSON array %s.\n", buffer);
    zh_json_free(&json);
}
```

### Создание сложного JSON объекта или массива (с вложенными структурами)

```c
#include "zh_json.h"

void app_main(void)
{
    esp_log_level_set("zh_json", ESP_LOG_ERROR);
    // Создание вложенного объекта
    zh_json_t json_sub_obj = {0};
    zh_json_init(&json_sub_obj);
    zh_json_add_char(&json_sub_obj, "Subname 1", "Hello world!");
    zh_json_add_int(&json_sub_obj, "Subname 2", -123456);
    zh_json_add_float(&json_sub_obj, "Subname 3", 1234.56789, 2);
    zh_json_add_bool(&json_sub_obj, "Subname 4", true);
    char sub_obj_buffer[128] = {0};
    zh_json_object_create(&json_sub_obj, sub_obj_buffer);
    zh_json_free(&json_sub_obj);
    // Создание вложенного массива
    zh_json_t json_sub_array = {0};
    zh_json_init(&json_sub_array);
    zh_json_add_char(&json_sub_array, NULL, "Hello world!");
    zh_json_add_int(&json_sub_array, NULL, -123456);
    zh_json_add_float(&json_sub_array, NULL, 1234.56789, 2);
    zh_json_add_bool(&json_sub_array, NULL, true);
    char sub_array_buffer[64] = {0};
    zh_json_array_create(&json_sub_array, sub_array_buffer);
    zh_json_free(&json_sub_array);
    // Создание основного объекта с вложенными структурами
    zh_json_t json_complex = {0};
    zh_json_init(&json_complex);
    zh_json_add_char(&json_complex, "Name 1", "Hello world!");
    zh_json_add_int(&json_complex, "Name 2", -123456);
    zh_json_add_float(&json_complex, "Name 3", 1234.56789, 2);
    zh_json_add_bool(&json_complex, "Name 4", true);
    zh_json_add_object(&json_complex, "Name 5", sub_obj_buffer);
    zh_json_add_array(&json_complex, "Name 6", sub_array_buffer);
    char complex_buffer[256] = {0};
    zh_json_object_create(&json_complex, complex_buffer);
    printf("JSON complex object %s.\n", complex_buffer);
    zh_json_array_create(&json_complex, complex_buffer);
    printf("JSON complex array %s.\n", complex_buffer);
    zh_json_free(&json_complex);
}
```

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| **Максимальная емкость** | 65 535 элементов |
| **Тип индекса** | uint16_t (16-бит) |
| **Управление памятью** | heap_caps_calloc, heap_caps_realloc, heap_caps_free |
| **Параметры памяти** | MALLOC_CAP_8BIT |
| **Потокобезопасность** | Не является потокобезопасным |
| **Версия ESP-IDF** | >= 5.0 |
| **Платформа** | Серия ESP32 |
| **Язык** | C (C99) |

## Коды ошибок

| Код ошибки | Описание |
|------------|----------|
| `ESP_OK` | Операция выполнена успешно |
| `ESP_ERR_INVALID_ARG` | Неверный аргумент (NULL указатель) |
| `ESP_ERR_INVALID_STATE` | JSON не инициализирован или уже инициализирован |
| `ESP_ERR_NO_MEM` | Ошибка выделения памяти (не хватает памяти) |
| `ESP_FAIL` | Общий сбой |

## Дополнительные заметки

- **Накладные расходы памяти**: Каждый элемент требует дополнительной памяти для указателей во внутренних массивах
- **Производительность**: O(1) для добавления элементов, O(n) для создания JSON строки
- **Лучшие практики**:
  - Всегда инициализируйте JSON перед использованием
  - Освобождайте JSON по завершении, чтобы избежать утечек памяти
  - Учитывайте ограничение максимального размера (65 535 элементов)
  - Для вложенных структур создавайте объекты/массивы отдельно и передавайте их в основной объект
